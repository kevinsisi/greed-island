# 潮汐遠征 · 本地 3D 原型

入口：`/prototype-3d`。目前本機預覽為 `http://127.0.0.1:4178/prototype-3d`。

這份原型在登入、世界資料 provider 之外獨立載入。任務、生命、卡片與 NPC 都只寫入 `greed-island.prototype3d.v1`；不讀取正式帳號、不呼叫正式 API。它不代表已接上正式世界的 Command/Event 規則。

## 遊玩

- WASD／方向鍵移動，Shift 快跑；手機使用左下搖桿。
- 按住場景拖曳轉動鏡頭；滾輪縮放。
- E 或互動按鈕與目標互動；1／2／3 或卡片按鈕施放；Space 重用選中卡片。
- M／迷你地圖開啟完整海圖，N／島民見聞觀察 NPC。見聞面板不暫停世界；地圖、說明、卡冊與對話暫停。
- 港口接任務 → 收集三枚光種、擊退石衛 → 使用渡風開封印 → 取晶核 → 回米拉交付。
- 倒下後可回港口，保留任務與遭遇進度；已用掉的刻印、護盾不會補回。
- 完成委託後，在米拉身旁選「準備下一趟」；右上「清空原型進度」才會確認後清掉全部 NPC 成長與營地物資。

## 可重玩的遭遇

每趟初始只有 1 枚刻印，能量恢復不會補充刻印。迎戰先備戰 1 秒，星火每發冷卻 1 秒；冷卻只在前景遊玩推進。兩個遭遇都可略過，每趟各只結算一次。

| 遭遇 | 安全路線 | 戰鬥路線 |
| --- | --- | --- |
| 林間藥草箱（-5, 1） | 回潮、30 能量、1 刻印 → 1 物資 | 75 HP；12 m 震擊造成 12 傷害 → 勝利得 3 物資 |
| 遺跡哨衛（5, 23） | 渡風、25 能量、1 刻印 → 2 物資 | 125 HP；12 m 震擊造成 18 傷害 → 勝利得 5 物資 |

每份營地物資在下一趟換 5 護盾，最多消耗 8 份換 40 護盾；多餘物資保留。護盾會先吸收實際傷害。本趟曾安全處理遭遇，島民會為下一趟多備 1 枚刻印（每趟最多多 1 枚，領取後不會再次發放）。NPC 的技能、信任、補給與記憶保留，主線和遭遇重新開始。

遭遇結果、物資、刻印與持久選擇統計同存一份資料；選項與傷害帶遠征 ID，拒絕舊遠征事件。刷新與死亡不會重領已結算遭遇。另一個分頁更新存檔時，舊分頁會停止寫入並要求重新載入；這是本機變更偵測，不是多玩家交易鎖。

## NPC 與卡面

米拉、芙恩、洛安與石衛各有目標、需求、技能、物資和最多八筆記憶。工作經驗會影響實際工作速度、產出或選擇。NPC 會記住附近卡牌與任務事件；石衛戰敗後休眠。這是有界的本地規則模擬，不會自我訓練或呼叫外部模型。僅前景遊玩推進，不做離線補算。舊版原型存檔會保留任務，補上 NPC 預設資料。

三張卡片都有原創生成插畫，卡冊顯示完整卡面。交付 JPG 在 `packages/web/public/prototype3d/cards/`；原始 PNG 在 `packages/web/artwork/source/`。

## 驗證

```sh
npm run test -w @greed-island/web
npm run build:web
npm run openspec:check
```

自動測試涵蓋任務循環、距離／資源限制、死亡、存檔、重開、NPC 變化與舊資料遷移。模型測試直接輸入座標，不能取代真實鍵盤、搖桿、碰撞與鏡頭的瀏覽器驗收。最新完成項目與限制見根目錄 `PROGRESS.md`。

推送使用 `feat/tideborn-3d-preview`。本次不合併主分支、不部署、不更動其他本機服務。
